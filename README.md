# CAP_project

### Categories, Algorithms, Programming

This repository contains several Julia packages transpiled from the corresponding GAP packages in the [CAP project][CAP_project].

## Release status

Its badge compares the version in this repository with the latest registered version, making it
clear when [@JuliaRegistrator][JuliaRegistrator] must be triggered after a version bump.
